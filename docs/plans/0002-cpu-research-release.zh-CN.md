# CPU 研究版本八周实施计划

[English](0002-cpu-research-release.md) | **简体中文**

状态：已接受，实施待启动。

日期：2026-11-01

## 目标与范围

八个有效开发周从实现启动时计算，现有 Windows 环境与构建验证作为起点。目标是交付 C++20 静态库形式的 CPU 研究版本，串起场景编译构建、多 World 仿真、默认刚体求解及本地查看。版本目标为 v0.1.0，各阶段完成情况依据实际成果记录。

核心交付包含开放插件与统一生命周期、逐 World 独立状态、默认 CPU 求解路径、官方示例及实验记录。重点扩展包含树形多体、基础关节、简单闭环、Python 本地操作及外部渲染器适配。Warp 仿真后端、CCD、可微分、传感器具体实现、SDF 技术路线及完整关节／机器人格式覆盖属于后续研究。

广泛形状支持保持长期方向。首批实现球、平面、盒的必要碰撞组合，凸体及其他形状按进展追加。每种形状分别记录解析、碰撞、仿真及查看支持。

## M1：运行骨架，第 1 周

- C++ 场景配置、逐 World 参数及编译构建路径。
- 插件初始化、资源管理、销毁及用户自定义数据与执行流程。
- 单 World 与同步批量推进，独立状态及模拟时间。
- 示例插件定义的运行输入通道及生效时点。
- 独立插件定义自己的状态和更新规则，由示例程序组装。
- 错误处理示范雏形：插件输出诊断，示例程序决定停止或继续。

交付静态库与单 World、多 World、外部插件三个小型示例。开发检查关注生命周期、状态隔离和编译后配置固定行为。插件版本、依赖及组合管理由用户负责，组件定义自身所需检查。

## M2：自由刚体，第 2 周

- 所需向量、矩阵、四元数和位姿运算；明确单位、坐标系及旋转速度语义。
- 质量、质心、惯量、初始位姿与速度，以及重力和外力输入。
- 默认平移及旋转增量势能，内部离散状态初始化与更新。
- 梯度、Hessian、Newton 迭代、线搜索及停止信息。
- 多 World 使用不同初始状态和编译前参数运行。

实验覆盖自由落体、主轴旋转、任意方向自由旋转及外力作用。研究记录包含导数检查、步长变化、能量与角动量表现。Backward Euler 对照先明确比较对象、方程及状态约定，独立对照实现按研究需要安排。

## M3：接触与静摩擦，第 3—4 周

- 形状局部变换、包围盒、候选对生成及碰撞过滤。
- 球、平面、盒的必要碰撞组合，逐项记录支持配对。
- 接触点、法向、间隙、切向基及接触历史。
- 柔顺法向接触势能及其导数。
- 零滑动静摩擦、滑动摩擦、投影残差及广义导数。
- 半光滑 Newton、线搜索、多接触冗余处理及外层接触更新。
- 残差、迭代次数、接触状态及失败上下文。

代表实验为球体落地、长方体落地、低于摩擦极限的推力、滑动、斜面静止和简单堆叠。法向阻尼等待定模型在实现前单独讨论。

第 4 周复核静摩擦承载、多接触收敛和失败案例，据此调整凸体、更多形状及后续扩展进度，并记录调整原因与影响。

## M4：多体与关节，第 5—6 周

- 连杆、固定／浮动基座、机构树及附加闭环连接的编译构建。
- 固定连接、转动关节及移动关节。
- 正向运动学、运动映射及默认求解器需要的导数。
- 连杆惯性、外力及接触向机构变量的映射。
- 理想闭环硬约束、初始化检查、约束残差及冗余诊断。
- 关节力／力矩和明确支持的外力输入。
- 面向代表机构的原生中间解析层，为格式适配器提供接入路径。

实验包含单摆、串联双连杆、移动关节机构、四连杆及机构与地面接触，并继续覆盖多 World。关节限位、位置驱动、关节干摩擦及弹性连接依据专项决策与进展追加，各自记录实际状态。

## M5：使用路径与研究交付，第 7—8 周

- Python 本地配置、编译构建、推进、输入提交和结果读取。
- 命令行运行已有实验、选择配置及导出结果。
- 一个选定机器人格式的明确支持子集，记录来源及导入诊断。
- 一个外部渲染器适配，显示几何、位姿和选定诊断，支持选择查看 World。
- 选定 World 部分重置，恢复配置的初始状态并保持已编译参数。
- 官方插件组合的快照保存与恢复，覆盖单 World 和选定子集。
- 错误处理示范插件、结果汇总及调用者自行选择处理动作的示例。
- 固定实验配置、运行条件、原始结果、结论、已知问题及复现步骤。

首期快照实现目标为相同构建及兼容配置下续跑。跨版本迁移、复杂异步恢复及通用持久化格式属于后续工作。鼠标施力作为可追加输入，场景编辑进入重新配置与编译构建流程。具体机器人格式与渲染器在对应阶段前选择。这两周同时承担集成和问题修复。

## 贯穿要求与研究风险

多 World 与插件扩展从 M1 贯穿实施，各阶段保持共享只读模型、独立状态及编译前逐 World 参数。同步批量交互作为首期路径，异步调度保留为后续实现方向。模型结构与参数遵循 [ADR-0019](../decisions/0019-world-configuration-and-runtime-inputs.zh-CN.md)。

插件管理、错误分类和恢复策略由用户设计。官方插件与示例提供一种参考组合，具体协议与接口随模块设计确定。实验评价遵循 [ADR-0015](../decisions/0015-experiments-and-acceptance.zh-CN.md) 的官方研究范围，用户自行决定应用验收标准。

接触摩擦与多体耦合是主要研究风险，阶段复核以实际运行证据调整扩展范围。实现按针对性检查和参数化实验组织，控制测试文件数量。

最终支持表分别记录形状、关节、插件生命周期／重置／快照及后端的实际能力。版本候选交付包含可构建库、代表实验、Python 与外部查看器路径、复现记录及已知问题。远程托管和公开发布按后续安排推进。
