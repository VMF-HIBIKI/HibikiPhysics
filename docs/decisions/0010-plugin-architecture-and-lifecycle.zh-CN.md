# ADR-0010：插件化架构与生命周期

[English](0010-plugin-architecture-and-lifecycle.md) | **简体中文**

状态：Accepted（已接受）

日期：2026-11-01

相关工作：[ADR-0009：默认刚体研究配置](0009-incremental-potential-rigid-contact.zh-CN.md)。

## 背景

HibikiPhysics 支持围绕不同物理模型、状态表示、数值方法和执行后端开展研究。用户需要替换已有实现、扩展已有系统，并引入超出引擎初始能力分类的新功能。

DeepSeek Harness 为插件定义服务、依赖管理及可替换执行循环提供架构参考。HibikiPhysics 根据自身 C++ 运行时和物理计算需求应用这些原则。

## 候选方案

| 方案 | 取舍 |
| --- | --- |
| 固定引擎与预设算法插槽 | 预期内方案接入简单，扩展范围受内置插槽设计约束。 |
| 通用数学接口 | 提供共同装配语言，其假设限制新模型及数据需求。 |
| 开放插件协议与统一生命周期 | 选定方案，用户可以定义新能力，互操作规则由参与用户及组件定义。 |

## 决策

### 开放扩展

物理能力由插件提供。官方插件与用户插件使用相同的公开扩展机制。插件可以提供小型服务、包含自身状态的物理模型、完整子系统或其他插件的组合。

用户可以在独立开发的包中定义并注册新协议、配置类型、模型数据、运行状态、诊断及执行流程。注册机制支持新的能力身份，同时保持内核内置类型列表稳定。第三方插件可以定义协议，并通过共享协议包协作。

扩展契约覆盖三种用途：替换已有提供者、向已有子系统追加能力，以及提供拥有独立协议与执行流程的新子系统。

### 协议归属与组合

协议属于使用它的插件体系。插件身份、版本、依赖、提供者选择、组合及升级由用户管理。参与者定义自身的互操作、数据所有权及执行规则。场景编译构建执行所选组件需要的检查，并报告结果。具体协议及检查机制保持开放。

势能、残差、约束、投影和矩阵自由算子接口保留为具体算法体系的候选。具体数学接口、强制能力分类及通用的模型／离散／求解分层保持待定。这些概念可以用于组织默认实现，其接口通过真实扩展案例逐步形成。

模拟编排本身可以替换。默认的预测、接触、求解、提交顺序属于默认时间推进实现。插件可以公开内部扩展入口，也可以提供完整的替代流程。数据访问、同步、执行顺序与状态修改边界属于各流程的显式契约。

### 统一生命周期

运行时提供统一的注册、初始化、资源所有权、销毁及资源清理机制。用户或所选编排组件安排依赖及初始化顺序。销毁在释放资源之前协调进行中的工作及依赖使用者。注册项随其所属插件作用域释放。

插件声明实例作用域，区分不可变模型数据、持久模拟状态及可重建缓存。不同场景可以选择不同实现，并拥有独立的可变状态。跨插件访问遵循明确的所有权与生命周期契约。

所选执行流程定义检查点、回滚、提交及恢复的参与方式。支持重启的组件定义自身状态检查及重建规则。失败传播和恢复由用户设计，生命周期清理遵循资源所有权。

统一生命周期表示共同的管理规则。回调签名、状态存储机制、并发原语和二进制加载行为属于后续设计。

### 错误处理扩展

错误处理通过插件扩展。项目将提供官方示范插件与应用，展示诊断收集、结果汇总及调用者自行选择处理动作。错误分类、信息格式、处理协议、状态有效性规则和恢复策略由用户定义，具体接口保持待定。示例记录失败 World 及其时间／求解上下文，由应用选择后续动作。

### 默认研究配置

[ADR-0009](0009-incremental-potential-rigid-contact.zh-CN.md) 定义官方默认刚体研究配置，包括混合多体坐标、增量势能惯性、柔顺法向接触、理想硬闭环，以及采用半光滑 Newton 的非光滑静摩擦。

其中的物理与数值要求适用于该配置。其他插件组合可以选择不同模型和求解器，并声明各自的行为与验证要求。默认组合通过公开扩展机制组装，作为可复现的参考配置。

运行记录标识实际插件组合、实现版本、参数及执行策略。摩擦与阻尼属于可扩展能力；默认关节摩擦方向为保持零速承载的非光滑干摩擦，并可单独叠加黏性阻尼。具体关节摩擦协议与离散方式通过后续规格确定。

## 影响

扩展自由度包含协议、数据和流程定义。共享协议支持兼容体系内的复用与替换。用户选择适合自身组合的依赖管理、适配及验证方式，官方示例记录实际组合以支持复现。

[ADR-0011](0011-multi-world-batch-simulation.zh-CN.md) 将多 World 批量仿真及插件并行隔离确定为核心要求。专用数据布局和构建期绑定保留为可选设计。具体 C++ 接口、注册标识、静态／动态加载、二进制 ABI 及加载机制属于后续设计。运行组合按 [ADR-0019](0019-world-configuration-and-runtime-inputs.zh-CN.md) 保持固定。本记录确定已接受的原则，实现待完成。

## 验证

验证状态：待架构原型与实现。

- 完全通过公开扩展机制构建官方默认组合。
- 从独立项目接入具有自定义历史状态的摩擦插件，验证生命周期与回滚行为。
- 接入自定义多体表示和求解器，复用几何服务并拥有自身状态与数学模型。
- 在用户包中定义内核事先未知的服务协议，使两个用户插件通过该协议协作。
- 通过插件组合替换完整时间推进流程。
- 在同一进程中运行采用不同实现及独立状态的两个场景。
- 验证组件自定义检查、初始化清理、销毁及官方错误处理示例，记录实际组合以支持复现。
