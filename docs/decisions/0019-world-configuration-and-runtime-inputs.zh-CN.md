# ADR-0019：World 配置与运行输入

[English](0019-world-configuration-and-runtime-inputs.md) | **简体中文**

状态：Accepted（已接受）

日期：2026-11-01

相关工作：[多 World 仿真](0011-multi-world-batch-simulation.zh-CN.md)、[可视化](0014-visualization-and-diagnostics.zh-CN.md)、[快照](0017-snapshots-and-restoration.zh-CN.md)。

## 背景

批量仿真需要逐 World 参数差异与域随机化。稳定的运行模型为派生数据、插件执行及恢复提供明确基础，交互应用同时需要受控的输入通道。

## 候选方案

| 方案 | 取舍 |
| --- | --- |
| 运行时编辑模型并更新依赖数据 | 需要执行期间的修改、失效化及重建契约。 |
| 编译前配置与显式运行输入 | 选定方案，固定各编译实例的模型数据，通过声明的输入定义交互。 |

## 决策

### 生命周期与数据归属

World 遵循配置、场景编译构建、运行三个阶段。场景编译构建将场景、参数和插件配置生成可执行仿真实例，源码编译属于独立的开发操作。

配置阶段确定结构、逐 World 参数、初始状态、插件组合及域随机化规则。场景编译构建固定模型结构及物理参数，执行组件自定义检查，并准备碰撞、动力学和求解数据。兼容的不可变资产及模型数据可以共享，各 World 独立拥有演化中的仿真状态及插件历史。

已编译模型结构与参数在整个运行阶段保持固定，暂停和重置沿用这些配置。修改进入新一轮配置与场景编译构建流程。具体重建、资源复用及状态迁移机制保持待定。

### 域随机化

用户可以在场景编译构建前为各 World 分别设置或采样参数。插件声明支持的参数及合法范围，编译构建依据各 World 的实际取值准备派生数据。采样来源、种子及最终取值支持复现。

模型参数重新采样，包括质量、惯性及摩擦变化，进入新一轮配置与编译构建流程。部分重置沿用已编译参数，按重置策略恢复配置的初始状态及插件状态，其他 World 保持原状态。

### 运行输入

运行期间支持状态推进、结果读取及已编译配置明确开放的输入。插件声明输入语义、允许范围、校验方式及生效时点。驱动输入、控制目标及未来的鼠标外力交互属于候选输入，具体支持范围在对应功能设计时确定。

查看器交互通过相同的声明输入通道接入。模型编辑属于配置阶段，输入通道在固定模型及其声明能力范围内工作。运行记录可以标识实际输入及其模拟时间。

### 恢复与适用范围

快照标识已编译配置及逐 World 参数取值，恢复使用兼容的已编译配置。改变模型参数或结构的分支经过配置与编译构建，并明确状态迁移策略。

本记录更新此前关于参数覆盖、重置时随机化、查看器参数编辑及运行时机构连接的描述。逐 World 参数覆盖表示编译构建前的配置。具体接口、数据布局、编译构建算法及运行输入清单保持待定。

## 影响

域随机化支持同一批次内的不同参数组合，运行派生数据关联稳定的已编译配置。参数研究计入配置及编译构建成本，用户插件通过配置数据、编译构建行为及声明的运行输入保留扩展能力。

## 验证

验证状态：待实现。

开发检查将覆盖逐 World 编译参数差异、派生数据一致性、重置时参数保持、输入校验及兼容快照恢复。运行期间的模型编辑请求产生诊断，指向配置与编译构建流程。官方实验选择自身评价条件，用户按 ADR-0015 自行定义应用验收方式。
