# ADR-0012：使用方式与运行模式

[English](0012-usage-and-runtime-modes.md) | **简体中文**

状态：Accepted（已接受）

日期：2026-11-01

相关工作：[插件化架构与生命周期](0010-plugin-architecture-and-lifecycle.zh-CN.md)、[多 World 批量仿真](0011-multi-world-batch-simulation.zh-CN.md)。

## 背景

HibikiPhysics 服务物理研究，并为具身智能应用提供仿真能力。当前产品范围覆盖引擎、本地场景搭建与查看，以及可复现的仿真实验。未来可以由独立 Lab 项目在这些能力之上构建训练工作流。

## 候选方案

| 方案 | 取舍 |
| --- | --- |
| 各入口分别实现应用行为 | 局部定制直观，共同场景与模拟语义需要额外协调。 |
| 共享模拟语义与分工明确的入口 | 选定方案，C++、Python、命令行和可视化服务不同使用场景，共用兼容插件组合及模型／状态语义。 |
| 引擎与训练 Lab 集成交付 | 应用覆盖更广，同时增加任务、奖励、课程和训练框架职责。 |

## 决策

### 入口定位

| 入口 | 职责 |
| --- | --- |
| C++ | 独立可用的引擎与扩展基础，面向原生集成、算法研究和插件开发，支持单个及批量 World。 |
| Python | 本地脚本的一等入口，用于创建／加载场景、配置模型、控制仿真、打开查看器、检查状态及导出／分析实验。批量仿真能力可以作为引擎操作提供。 |
| 命令行 | 根据记录的配置执行可复现无窗口运行、回归场景、参数研究和性能测量。 |
| 可视化 | 可选的观察与交互能力，展示物体、关节、接触、力及求解诊断，支持选择单个 World 或子集。 |

各入口采用所选组合定义的场景含义、配置及结果协议。数值行为由所选组合决定。C++ 原生应用可以独立使用引擎，Python 和 GUI 集成为组合的可选能力。等价运行记录后端或配置之间的差异。

### Python 与 Lab 边界

短期 Python 交付支持本地场景搭建、仿真控制和查看。研究脚本可以通过受支持的引擎能力进行批量运行、部分重置和编译构建前的参数变化。

训练任务、奖励定义、回合管理框架、课程学习、强化学习算法集成及分布式训练编排属于更上层应用。未来可以由独立 Lab 项目通过公开引擎和插件契约提供这些功能。当前 Python 交付以本地仿真工作流作为验收范围。

多 World 隔离、部分重置及逐实例参数继续作为 ADR-0011 的引擎核心要求。未来 Lab 应用可以使用这些基础能力，并定义自己的动作、观测和任务语义。

### 运行模式与优先级

| 模式 | 用途与优先级 |
| --- | --- |
| 无窗口多 World 批量 | 仿真实验及未来具身应用的主要交付与性能路径，按选定推进策略推进模拟时间。 |
| 交互研究 | 面向一个场景或少量选定 World 的核心开发工作流，支持暂停、单步、重置与受控交互。 |
| 批量观察 | 检查批量中的选定 World 和采样诊断，观察频率与物理推进分别配置。 |
| 回放与检查 | 分析记录的轨迹或恢复受支持的快照，播放数据与可继续模拟的状态具有明确且独立的保证。 |

查看与控制遵循声明的快照／读取规则及声明的运行输入及重置边界。视觉布局偏移保持 ADR-0011 的逐 World 物理语义。[ADR-0016](0016-time-advancement.zh-CN.md) 已确定默认同步批量交互和可扩展异步推进方向，具体调度实现保持待定。

### 查看器与视觉观测

查看器服务人工观察和交互，视觉传感器为应用生成观测。两者均为可扩展能力，分别定义要求。所选组合支持离屏观测提供者时，无窗口执行可以使用对应能力。

[ADR-0014](0014-visualization-and-diagnostics.zh-CN.md) 确定由外部渲染器负责渲染，通过插件接入，并提供独立于渲染器的诊断。本地查看器作为采用外部渲染器的参考应用。

渲染后端、图像类型、保真度及离屏传感器的交付优先级保持待定。本地查看属于短期 Python 工作流，面向应用的视觉传感器范围通过后续讨论确定。

### 可复现运行

命令行与脚本运行记录场景／模型身份、插件实现及版本、参数、随机化配置、执行后端、推进策略、逐 World 结果及失败诊断。输出根据实际记录的能力支持后续分析、播放或恢复。

应用可以选择 C++、Python 或命令行入口运行等价仿真配置。查看器通过公开契约读取所选模拟状态和诊断。

## 影响

无窗口批量能力与本地交互研究指导初期交付。C++ 作为独立引擎基础，Python 提供便捷的本地搭建与查看入口。Lab 职责具有独立应用边界，引擎继续提供未来集成所需的批量能力。

具体 C++／Python 接口、绑定库、张量／数组交换、命令语法、场景文件格式、查看器实现、渲染后端及回放存储格式保持待定。实现属于后续工作。

## 验证

验证状态：待实现与工作流验收。

- 通过 C++ 引擎构建并运行原生无窗口仿真。
- 在 Python 中构建本地场景，推进、重置、交互查看、检查状态并导出结果。
- 无窗口运行已记录的多 World 配置，覆盖部分重置和编译构建前的参数变化。
- 按共同组合及记录的数值标准比较不同入口的等价运行。
- 观察选定 World，验证受控交互、状态隔离及仅用于展示的偏移。
- 验证记录结果和声明的播放／恢复能力，集中组织相关工作流用例以控制测试文件数量。
