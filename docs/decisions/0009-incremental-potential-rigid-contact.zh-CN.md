# ADR-0009：默认刚体研究配置

[English](0009-incremental-potential-rigid-contact.md) | **简体中文**

状态：Accepted（已接受）

日期：2026-11-01

相关工作：[架构方向](../architecture.zh-CN.md)、[构建与数值策略](0004-build-and-numerical-policy.zh-CN.md)。

## 适用范围

本记录定义刚体动力学、接触与摩擦的官方默认研究配置。其中的坐标选择、力学规律、求解策略及验收条件适用于该组合。[ADR-0010](0010-plugin-architecture-and-lifecycle.zh-CN.md) 定义开放插件架构与统一生命周期。其他组合可以提供自己的协议、数据、模型、求解器及执行流程，并明确兼容性和验证要求。具体数学扩展接口保持待定。

默认配置通过与用户相同的公开扩展机制组装。下述决策在这一范围内继续保持已接受状态。

## 背景

HibikiPhysics 以隐式刚体动力学、接触建模和非线性求解为研究方向。CPU 实现为受控实验提供参考模型。SuperDex 为旋转增量势能和柔顺表面接触提供参考。

设计讨论采用长方体自由旋转、平面法向接触、零滑动静摩擦及多接触点求解作为推导案例。实现与数值验证属于后续工作。

## 候选方案

| 方案 | 定位与取舍 |
| --- | --- |
| 增量势能刚体惯性与柔顺接触 | 选定的 CPU 模型，将惯性和保守接触组合为具有一致导数的标量目标。 |
| 直接离散 Newton–Euler 残差 | 动力学对照候选，需要独立定义残差、Jacobian 和全局收敛策略。 |
| 顺序冲量 | 后续接触对照候选，比较时明确其接触模型与时间离散假设。 |

## 决策

### 状态与时间离散

模型使用质心平移和刚体朝向。四元数保存朝向，局部三维旋转增量定义优化更新。每个独立动态刚体提供六个局部运动变量。机构连杆的位姿由根状态和关节坐标计算。

Backward Euler 作为初始时间离散基线。选定的增量势能属于 Backward Euler 型模型。后续积分器比较保留该基线，并明确惯性模型、初始化、接触规律、时间步长和求解容差。直接离散 Newton–Euler 方程的 Backward Euler 实验属于需要单独定义的候选模型。

旋转状态保留所选惯性模型需要的有限差分信息。物理角速度输入、内部离散速度和步间等效角速度具有明确语义。初始化与重建策略通过后续专项决策确定，推导示例中的连续切向初始化作为候选方案。

### 混合多体坐标与连接

机构树采用约化关节坐标，独立刚体采用自由位姿。浮动机构增加自由根位姿，固定基座机构使用给定的根变换。正向运动学将主状态 `q` 映射为各连杆的质心位姿 `X_i = K_i(q)`。关节流形区分存储坐标与局部更新维数，派生连杆位姿供碰撞和渲染使用。

树关节的几何关系由运动学参数化满足。理想闭环和理想跨机构连接使用显式硬约束 `g(q) = 0`，按记录的求解容差保持连接。弹性连接使用明确配置的柔顺势能，以及另行确定的一致耗散模型。连接的力学语义由配置明确选择。

闭环机构以生成树和附加闭合边表示。每条闭合边仅提供其关节类型要求的几何条件。一致初始构型、装配分支、冗余约束行及机构奇异姿态具有明确的验证和诊断。连接与机构拓扑在场景编译构建时固定，修改按 [ADR-0019](0019-world-configuration-and-runtime-inputs.zh-CN.md) 进入新一轮配置与编译构建流程。

独立刚体与机构连杆共享刚体惯性、几何和接触项。各连杆的离散惯性势在正向运动学位姿上计算，预测值由时间积分器固定。广义坐标导数遵循链式法则。在一致局部坐标中，`grad_q E = A^T grad_X E`，精确 Hessian 同时包含 `A^T H_X A` 和由连杆空间梯度加权的运动学映射二阶导数。近似求解方向矩阵具有明确标识，并接受原始残差检查。

所有参与刚体的接触点位置和相对切向位移通过同一套运动学映射计算。相应 Jacobian 将自由位姿与关节的混合增量映射为接触运动。互相耦合的刚体与机构在其连接系统中联合求解。

少量连杆的最大坐标机构作为参考路径，使用相同刚体势能和显式关节约束，验证运动学导数转换及带约束运动。约化机构树与自由刚体组成的混合方案作为主组织方式。关节限位、驱动和关节摩擦通过后续规格分别确定力学或约束语义。

### 增量势能

对于质量为 `m`、质心为 `x`、朝向为 `R` 的刚体，时间步长为 `h`，质量二阶矩为 `J`，固定预测为 `x_tilde` 和 `R_tilde`，目标包含：

```text
平移惯性 = m / (2 h²) * ||x - x_tilde||²
旋转惯性 = 1 / (2 h²) * tr((R - R_tilde) J (R - R_tilde)^T)
平滑基础 E = 平移惯性 + 旋转惯性 + 接触势能
```

恒定重力可以并入 `x_tilde = x_n + h v_n + h² gravity`。该约定将重力计入一次。预测值在一个时间步的非线性求解期间保持固定。

### 无摩擦柔顺接触

表面采样点 `i` 具有固定的物体坐标偏移 `r_i`，有效刚度 `k_i` 包含其求积权重。对于经过原点、单位法向为 `n` 的平面，其有符号间隙为 `d_i = n^T (x + R r_i)`。

参考接触势能为 `U_i = 0.5 k_i max(0, -d_i)²`。该有限刚度模型允许穿透并产生法向力。表面采样、求积和平滑策略在接触实现阶段进一步确定。分段二次模型具有连续一阶导数，二阶导数在零间隙处发生切换。

对于局部变量 `q = (delta_x, delta_theta)`，令 `a_i = R r_i`、`j_i = (n, a_i × n)`，`B_i` 为间隙的 Hessian。导数约定为：

```text
接触梯度  = U_i' * j_i
接触 Hessian = U_i'' * j_i j_i^T + U_i' * B_i
```

该平面模型的间隙 Hessian 旋转块为 `sym(n a_i^T) - (n^T a_i) identity`，平移块和混合块为零。外积项提供平移与旋转之间的耦合。接触梯度的负值给出法向力及其相对于质心的力矩。

### 静摩擦约定

对于采样点 `i`，`p_i(q)` 为当前材料点位置，`p_i^0` 为时间步开始时的位置，`T_i` 为正交单位切向基。二维切向位移为 `s_i = T_i^T (p_i(q) - p_i^0)`。

内层求解期间固定法向载荷 `Nbar_i >= 0`，摩擦上限为 `c_i = mu_i Nbar_i`。二维阻力变量为 `lambda_i`，实际切向力为 `-T_i lambda_i`。摩擦规律为：

```text
粘着：s_i = 0，||lambda_i|| <= c_i
滑动：lambda_i = c_i s_i / ||s_i||，适用于 ||s_i|| > 0
```

零滑动指一个时间步内离散材料点的切向位移为零。静摩擦验收同时检查单步容差和持续加载下的累计漂移。初始库仑规律采用单一摩擦系数。

### 增量势能与联合残差

令 `E(q)` 包含惯性、保守法向接触和其他单独接受的平滑项。固定载荷与切向几何后，目标为：

```text
最小化 Phi(q) = E(q) + sum_i c_i ||s_i(q)||
满足理想闭环与连接的 g(q) = 0
```

范数在零点保留集合值次梯度，其次梯度关系与上述粘着、滑动规律等价。

令 `J_i = partial s_i / partial q`，`C_i = {lambda : ||lambda|| <= c_i}`，`Pi_Ci` 表示到该圆盘的欧氏投影。联合方程为：

```text
r_q = grad E(q) + G^T nu + sum_i J_i^T lambda_i = 0
r_g = g(q) = 0
r_f,i = lambda_i - Pi_Ci(lambda_i + rho_i s_i(q)) = 0
```

其中 `G = partial g / partial q`，`nu` 为理想连接的乘子。弹性连接势能计入 `E`。仅包含自由刚体和摩擦的系统省略闭环行及其乘子。

正的算法参数 `rho_i` 单位为 N/m，用于数值尺度调整；收敛后的摩擦规律与其取值无关。零半径圆盘表示切向力为零。

半光滑 Newton 使用投影的广义导数及一致的力学导数，求解上述原始—对偶方程。旋转沿用 ADR-0009 的局部更新。固定法向载荷与切向几何后，非光滑目标具有明确含义；非线性旋转几何仍需要全局化策略与收敛检查。

### 参考方法与外层更新

少量接触点的主动集用例提供可独立核验的参考解。粘着点施加零切向位移约束，摩擦力由带约束的平衡方程求出。力的上限及滑动方向一致性用于检查分类结果。参考求解器与主求解器共享力学模型和摩擦规律。

外层迭代根据当前解更新法向载荷和耗散接触几何。内层固定这些量，保守接触在试探状态下重新计算。外层处理新接触和接触释放。稳定采样点标识及切向坐标一致性支持热启动。

### 投影导数与 Newton 系统

对于一个接触点，令 `y = lambda + rho s`、`u = y / ||y||`。圆盘半径 `c` 为正时，投影导数 `D` 为：

```text
||y|| < c：D = identity
||y|| > c：D = (c / ||y||) (identity - u u^T)
||y|| = c：D_gamma = identity - gamma u u^T，0 <= gamma <= 1
c = 0：   D = 0
```

边界矩阵集合为 Clarke 广义 Jacobian。严格内部与外部采用各自的精确分支导数。边界处沿用上一次已接受状态的分支，新接触优先采用内部分支。线性模型或线搜索失败时，可以重试另一侧边界导数。浮点边界容差仅用于分支选择；投影计算、残差和最终力上限保持原定义。诊断记录分支选择和重试。

对于一个接触点与理想连接，广义 Newton 矩阵的分块形式为：

```text
[ H_L       G^T   J^T        ] [delta_q     ] = -[r_q]
[ G         0     0          ] [delta_nu    ]    [r_g]
[-rho D J   0     identity-D ] [delta_lambda]    [r_f]
```

其中 `H_L = Hessian(E) + sum_j nu_j Hessian(g_j) + sum_i,alpha lambda_i,alpha Hessian(s_i,alpha)`。主状态采用约化坐标时包含运动学曲率项。多个接触点堆叠摩擦行与对偶列。粘着内部的导数分支恢复 `J delta_q = -s`。完整矩阵按一般原始—对偶系统处理。

### 残差线搜索与保护措施

令 `F = (r_q, r_g, r_f)`、`z = (q, nu, lambda)`、`Fhat = W F`。固定行尺度 `W` 使力、力矩、闭合位置、闭合朝向和摩擦残差具有可比较的尺度。秩检测与最小范数求解同时使用未知量尺度。尺度在一次内层求解期间保持固定。

线搜索评价函数为 `Psi(z) = 0.5 ||Fhat(z)||²`。自由平移、局部旋转、关节坐标和乘子修正使用同一个试探系数 `alpha`。自由旋转采用 `exp(skew(alpha delta_theta)) R`，关节更新采用各自的流形运算，随后执行正向运动学。试探对偶力允许位于摩擦圆盘外部。每次试探重新计算原始投影及完整力学残差。

对于充分准确求解的 Newton 方程，参考充分下降条件为：

```text
Psi(z_trial) <= Psi(z) - sigma alpha ||Fhat(z)||²
```

回溯从完整步开始。示例值 `sigma = 1e-4`、缩减系数 `0.5` 保留为实验候选。边界选择、近似线性求解和秩亏可能使当前方向无法通过该检查；该条件作为接受规则，配套明确的失败报告。

保护流程依次检查归一化线性残差、重试符合条件的边界导数，再允许采用信赖域或带阻尼的残差最小化方向。保护方向使用与预测下降相适应的接受规则，并检查原始残差的实际变化。达到重试上限后报告失败，保留上一次已接受的模拟状态。代数阻尼影响搜索方向，最终接受条件检查原始摩擦规律。

无附加约束的无摩擦平滑参考保留基于目标函数的 Newton 与 Armijo 回溯。硬连接和摩擦采用本节定义的联合残差评价函数。

### 冗余接触与力分配

所有接触采样点及其摩擦圆盘均保留。平放长方体的四个底面点提供八条切向约束，而独立的一阶切向组合只有三个。重复约束及多个可行力分配可能导致 Newton 系统秩亏。

小规模 CPU 参考实现采用秩揭示 QR 或 SVD。一致线性系统使用带尺度的最小范数修正；不相容的线性模型使用最小二乘修正，并检查实际残差变化。秩阈值和线性残差进入日志。内部采用约束约简时，最终接受检查仍覆盖完整原始残差及每个采样点的摩擦上限。

某个力分配超出单点圆盘时，刚体仍可能具有其他可行粘着解。联合求解允许力重新分配。最小范数规则选择数值修正，完整投影残差判断摩擦可行性。线性系统奇异本身仅提供代数诊断信息。

稳定采样点标识和一致的切向基支持摩擦力热启动。可选的辅助力选择问题可以在保持合力、合力矩及全部摩擦圆盘限制的条件下，最小化相对于历史力的变化；其实现属于后续工作。数值扰动及其对残差和累计漂移的影响共同记录。

### 外层一致性与最终接受

外层迭代更新法向载荷及耗散接触几何。内层固定这些量，保守接触在试探状态下重新计算。外层边界处理新接触与接触释放，零法向载荷对应零半径摩擦圆盘。

最终接受条件同时检查归一化力学残差、硬连接的位置与朝向误差、投影残差、粘着位移、圆盘可行性及外层载荷与接触一致性。更新后的载荷还用于重新评估候选状态下、按参数冻结约定计算的力学残差。小修正用于判断进展或停滞，上述残差与可行性条件用于判断收敛。

状态区分收敛、迭代上限、停滞、线搜索失败和数值失败。仅收敛步骤自动提交。具体数值容差、尺度公式、外层松弛及迭代预算通过后续规格确定。

## 影响

混合组织减少树形机构的运动变量，并通过正向运动学保持树关节几何关系。硬闭环增加乘子及对秩敏感的鞍点结构。运动学二阶导数、一致初始化和关节空间诊断增加工程工作。最大坐标参考用例用于验证共享模型。

CPU 研究模型组合 Backward Euler 型刚体惯性、柔顺法向接触和非光滑库仑摩擦。静摩擦支持零离散滑动下的承载，实现验收衡量残余滑动及持续加载下的漂移。原始—对偶变量、广义导数和考虑秩亏的线性代数增加实现成本。

半光滑 Newton 为摩擦求解主线。少量接触点的主动集用例提供独立参考解，近端投影迭代和速度正则化摩擦保留为可选对照。速度正则化的低速蠕动超出已接受的静摩擦行为范围。

本次接受范围为数学架构和上述求解策略。初始角速度构造、法向阻尼、表面求积、法向接触平滑、正式数值参数及高阶积分器通过后续规格确定。案例参数保留为实验候选。实现与物理误差研究属于后续工作。

## 验证

验证状态：待实现与实验。

- 使用方向有限差分检查平滑项局部梯度、Hessian 向量积及力学 Jacobian 向量积。
- 比较最大坐标参考与约化坐标的摆、滑块用例，验证正向运动学、局部 Jacobian 和 Hessian。
- 验证固定与浮动根、分支树、四连杆和曲柄滑块闭合，以及机构与静摩擦接触的联合求解。记录闭合误差、秩变化及失败步骤的一致状态恢复。
- 检查法向力、力矩及平移与旋转耦合，覆盖对称支撑和倾斜接触。
- 验证圆盘投影及分支导数，覆盖边界、零半径圆盘和导数重试行为。
- 比较主动集参考解与半光滑 Newton，覆盖摩擦极限以下、边界及以上的推力、斜面粘着、载荷反转与接触释放。
- 覆盖单点、两点及四点支撑，检查秩诊断、力重新分配、全部摩擦上限、合力与合力矩，以及累计粘着漂移。
- 验证线搜索残差下降、外层一致性及明确的失败处理，记录秩、线性残差、分支选择和迭代次数。
- 按记录的 Backward Euler 基线，对主轴自由旋转、一般自由旋转和平面接触进行步长与容差比较。相关用例采用参数化测试集中组织，控制测试文件数量。
