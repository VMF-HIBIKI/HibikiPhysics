# ADR-0014：可视化与诊断

[English](0014-visualization-and-diagnostics.md) | **简体中文**

状态：Accepted（已接受）

日期：2026-11-01

相关工作：[插件化架构](0010-plugin-architecture-and-lifecycle.zh-CN.md)、[多 World 仿真](0011-multi-world-batch-simulation.zh-CN.md)、[使用方式与运行模式](0012-usage-and-runtime-modes.zh-CN.md)、[场景与资产](0013-scenes-and-assets.zh-CN.md)。

## 背景

本地场景查看与多 World 实验需要物理调试、求解诊断及可复现的失败分析。外部渲染器或宿主应用负责渲染，HibikiPhysics 提供可扩展接入及独立于渲染器的诊断能力。

## 候选方案

| 方案 | 取舍 |
| --- | --- |
| 引擎自有渲染器与内置调试界面 | 集成直接，增加图形实现工作，并将查看能力绑定到具体渲染器。 |
| 外部渲染、插件化适配与独立诊断 | 选定方案，通过明确的数据与交互契约支持不同宿主应用及无窗口分析。 |

## 决策

### 渲染边界

外部渲染器负责图形渲染。HibikiPhysics 提供场景与几何引用、物体变换、World 身份及诊断信息。渲染适配器将这些数据转换为目标渲染器的资源和更新操作。渲染器或宿主应用负责窗口、相机、材质、光照、绘制及界面。

用户可以通过公开扩展机制为任意渲染器开发适配插件。实际兼容性由各适配器声明的能力确定。官方本地查看应用以外部渲染器为基础，提供参考集成。渲染引擎选择、交换协议和同步机制保持待定。

可视资产与碰撞表示可以分别配置，通过稳定标识与局部变换关联。物理诊断可以描述接触点、力箭头、关节轴等调试内容，适配器决定展示方式。用户插件可以提供自己的诊断与展示能力。

### 本地检查与交互

参考查看工作流覆盖相机操作、物体选择、场景／连杆层级、显示控制、可视／碰撞几何检查及物理调试叠加。相关显示包括包围盒、采样点、接触法向／力、关节坐标系／轴／限位、闭环连接、反作用力和约束误差。

仿真控制包含运行、暂停、单步和重置。运行交互按 [ADR-0019](0019-world-configuration-and-runtime-inputs.zh-CN.md) 使用已编译配置明确开放的输入。施加力／力矩、驱动目标及鼠标施力作为后续功能设计的候选输入，插件声明输入校验及生效时点。模型参数编辑归入配置与新一轮场景编译构建流程。可复现运行可以记录实际执行命令及其模拟时间顺序。

### 多 World 观察

查看支持单 World 聚焦、选定 World 排列及基于异常的 World 选择。显示偏移仅影响展示，干预和暂停命令明确标识作用范围。

显示 World 数量、观察频率及诊断详细程度独立于物理推进配置。查看使用一致快照或声明的读取视图。批量摘要用于定位失败或异常 World，再进行详细检查。调度及一致性机制属于后续设计。

### 诊断能力

诊断独立于渲染运行，面向命令行、Python、分析及查看工具提供数据。

| 层次 | 内容与用途 |
| --- | --- |
| 运行摘要 | 逐 World 结果、耗时、接触数量、迭代次数及失败原因，用于批量监控。 |
| 物理检查 | 位姿、速度、接触与关节作用力、闭环误差、粘着漂移及模型特定物理指标。 |
| 求解追踪 | 残差历史、线搜索行为、秩诊断、约束状态切换及详细停止原因。 |

插件可以定义指标、事件、调试数据及专用分析或展示工具，并声明含义、单位、采样时间、所属 World 和适用范围。具体求解器的诊断语言由 ADR-0010 中对应插件协议定义。

采集可按 World、指标、时间区间及详细程度选择，并具有明确的采样和容量控制。运行摘要支持持续监控，详细追踪按需启用。同一份诊断信息可用于导出与自动分析。采集上限及截断情况显式报告，便于正确解释保留的证据。

### 失败分析与回放

失败记录将 World、模型／插件组合、参数、停止原因与可用历史及恢复数据关联。采集可以保留异常附近的有限窗口和受支持的状态快照。

轨迹播放记录选定时刻的位姿、显示数据和诊断。可继续模拟的快照包含兼容模型／配置引用，以及续跑所需的插件权威状态。两类保证沿用 ADR-0012 和 ADR-0013 的区分。存储格式、记录频率及触发实现保持待定。

### 查看器与传感器边界

查看器服务人工观察和交互。视觉传感器服务应用观测，可通过适配器连接外部渲染。传感器覆盖、采样及交付要求通过单独决策确定。本地查看与无窗口物理诊断指导当前交付。

## 影响

引擎提供本地检查与无窗口批量分析能力，外部渲染器提供图形功能。实现需要适配器及明确的快照／命令契约。详细采集的性能与内存成本可以配置，并在验证中测量。

具体接口、诊断 schema、事件传输、文件格式、存储工具、界面布局、参考渲染器及渲染同步保持待定。本记录确定已接受的边界与能力，实现待完成。

## 验证

验证状态：待实现与可视化／诊断验收。

- 通过适配器连接外部渲染器，验证几何身份、变换及调试展示。
- 在无窗口运行中采集并导出物理与求解诊断。
- 检查选定 World，验证仅用于展示的偏移、状态隔离及明确的干预范围。
- 从独立插件增加自定义诊断与展示。
- 检查采样、容量／截断报告及不同采集层次的开销。
- 记录失败 World，定位其配置与停止原因，并执行声明的播放或恢复流程。
- 验证安全交互命令及其执行顺序，相关用例共享参数化工作流以控制测试文件数量。
