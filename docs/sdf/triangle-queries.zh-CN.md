# 局部坐标系的三角网格查询

[English](triangle-queries.md) | **简体中文**

`TriangleMeshQueries` 持有网格与一份只读空间索引。构造时可传入查询提供者，便捷构造函数使用 CPU 提供者。每个包围盒包住一个被引用的三角面，编号沿用从零开始的源面索引。

`Closest` 返回局部最近表面点、以米为单位的无符号欧氏距离及面编号。默认提供者在等距时选择最小编号。面内、边和顶点均参与判定。`RayHits` 依次按前向射线参数与面编号排序，参数乘以输入方向得到位移。命中特征分为面内、边、顶点和共面。同一公共边界可对应多条命中记录。共面射线返回其与每个相交三角形的首个前向交点。穿越次数由实体分类层处理。

坐标和方向须有限，射线方向须非零。叶节点使用经缩放的双精度运算，以 32 倍机器 epsilon 的重心坐标窗口识别边界舍入误差。计算结果超出数值范围时可抛出 `std::overflow_error`。
