# Stackless Morton BVH traversal

**English** | [简体中文](stackless-lbvh.zh-CN.md)

`CpuSpatialOverlapPlugin()` selects the stackless Morton tree for CPU broad phase. Its implementation name is `hibiki.stackless_lbvh`. To select this provider explicitly, include `<HibikiPhysics/StacklessSpatialIndex.h>` and register `StacklessSpatialOverlapPlugin()`, or call `MakeStacklessSpatialOverlapProvider()` directly. Box hits and candidate pairs follow traversal order. Each pair contains two distinct caller IDs with the smaller ID first. [Overlap contract](../geometry/spatial-index.md)

## Following escape links

The index builds the Morton hierarchy in preorder, then records one extra `std::size_t` per node. The root escapes to the end of the array. A left child escapes to its right sibling, and a right child inherits its parent's escape. A single forward pass assigns every link. [Morton construction](morton-lbvh.md)

A box query keeps a node index. A disjoint node sends the query to its escape. At an intersecting node, the query emits the ID if it is a leaf and advances one position. For self-pairs, each source leaf starts this same walk immediately after itself. Every later leaf appears in that suffix exactly once. Intersecting leaves emit their IDs with the smaller ID first. Traversal uses constant scratch space in addition to the returned candidates.

Construct `StacklessSpatialOverlapIndex index(entries)` and pass a `std::size_t` to `index.Overlaps(bounds, visits)` or `index.OverlapPairs(visits)` to count node bounds tests. Rejected nodes count as visits. The pair count sums the bounds tests in all suffix walks. The scan that selects source leaves performs no bounds tests. Each concurrent query can supply its own counter. [Installed consumer tests](../../tests/install-consumer/StacklessSpatialIndex.cpp)

## Comparison with an explicit stack

The regression builds both indexes with the same Morton builder over 1,024 boxes generated by `std::mt19937` with seed 52. It queries every input box, then enumerates all self-pairs. The reference pushes right and left children onto a vector. At a source leaf the remaining stack holds the same forest as the stackless suffix. The test compares sorted IDs and node visits per box, then compares the sorted pairs and total pair visits. [Comparison program](../../tests/spatial/StacklessTraversal.cpp)

| Workload | Candidates in either walk | Node visits in either walk | Stackless median (µs) | Explicit-stack median (µs) |
| --- | ---: | ---: | ---: | ---: |
| 1,024 box queries | 3,360 | 46,462 | 361.0 | 580.4 |
| All self-pairs | 1,168 | 17,432 | 86.8 | 104.7 |

These are elapsed times on Windows x64, Ryzen 7 9700X, clang-cl 22.1.6, Release. Each measurement covers a complete workload including result allocation. The program warms both indexes, alternates measurement order, and reports the median of nine runs per traversal. Construction and correctness comparisons happen outside the timed section. Reproduce with the prepared Windows toolchain:

```powershell
cmake --preset windows-release -DHIBIKI_BUILD_ACCEPTANCE=OFF
cmake --build --preset windows-release --target hibiki_stackless_traversal
ctest --preset windows-release -R '^geometry\.stackless_traversal$' -V
```
