# 带元数据的 LBVH 剪枝

[English](metadata-pruning.md) | **简体中文**

`FilteredMortonPlugin()` 注册带过滤能力的重叠查询提供者。每个叶子携带由调用方定义的归属与类别两个标签。仅当所有后代叶子的标签相同，节点才记录该统一摘要。查询谓词接收两组元数据，要求确定且无副作用。谓词排除统一摘要时可跳过整棵子树。混合节点继续下降，叶子执行精确过滤。

单盒查询使用指定源 ID 的元数据，包围盒与谓词允许时可命中自身。无序自配对只输出一次，较小 ID 的标签作为谓词第一参数。普通重叠查询覆盖原始候选。基线在每次谓词求值时读取查询侧元数据。每次查询独立记录访问节点数、查询元数据读取次数、叶测试和剪掉的内部子树。
