# 架构方向

[English](architecture.md) | **简体中文**

状态：首个实现里程碑的提议基线。

## 核心边界

C++20 库负责正式的 CPU 仿真流程，支持无窗口运行和独立 C++ 构建。示例及 sandbox 使用公共 API。Warp 实验使用独立的可选环境，并定义明确的对照数据。

## 模块

| 模块 | 职责 |
| --- | --- |
| Core | 句柄、存储、资源生命周期和诊断 |
| Math | 引擎需要的数学运算 |
| Geometry | 形状、包围体和几何查询 |
| Collision | 宽相候选生成及窄相接触生成 |
| Dynamics | 刚体状态、外力与积分 |
| Constraints | 接触及后续关节约束定义 |
| Solver | 约束求解与迭代诊断 |
| World | 仿真生命周期及阶段编排 |

底层模块提供明确的输入输出。World 组合仿真阶段。渲染和实验代码依赖引擎接口。

## 初始设计原则

- World 管理刚体和形状的生命周期。
- 公共句柄携带代数信息，用于检测失效句柄。
- 内部存储布局通过公共接口封装。
- 持久状态与每步临时数据具有独立生命周期。
- 仿真阶段记录输入、输出及同步要求。
- 诊断提供数量、迭代统计及计时数据。
- 物理行为附带数值约定与容差说明。

这些原则通过 ADR 和小型实验细化。构建目标拆分、数据布局和并行执行随测量需求演进。

## 规划中的构建目标

- `hibiki::physics`：首期公共 C++ 静态库目标。
- `hibiki_tests`：自动化正确性检查。
- `hibiki_benchmarks`：可复现性能测量。
- 示例与 sandbox 可执行程序：API 使用与仿真观察。

当前仓库提供目录结构。可用构建目标与命令由工程基础里程碑引入。

[Windows 开发环境实施计划](plans/0001-windows-environment.zh-CN.md)定义初始静态库包和独立工具链用例，共享库支持属于后续扩展。
