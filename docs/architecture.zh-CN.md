## 当前实现

公共数学类型 `Vec3`、`Quat` 和 `Transform` 用于向量运算、单位旋转和刚体位姿组合。位姿将点和方向从局部坐标系映射到父坐标系。[四元数与刚体位姿](decisions/0021-quaternion-and-rigid-transform.zh-CN.md)。

几何插件为八种解析形状提供局部和世界坐标系下的轴对齐包围盒。点查询覆盖平面有符号距离、闭半空间与五种闭实体的包含判断，以及有限矩形面片最近点。六种支持包含判断的形状均可用刚体位姿查询世界点。应用通过 `config.Add(HibikiPhysics::GeometryLibraryPlugin())` 注册该插件。[几何库决策](decisions/0020-geometry-library-plugin.zh-CN.md)。

C++20 静态库目标 `hibiki::physics` 已公开构建信息接口及 `HibikiPhysics::Plugin` 基类。Windows 工具链、编辑器、调试和环境复现已完成验证。[Windows 验收记录](environment/acceptance.zh-CN.md)。

插件作者包含 `<HibikiPhysics/Plugin.h>`。`CapabilitySlot<T>` 将入口名与协议类型关联，并保留只读限定。`MakePlugin(callback, slots...)` 使用同一组描述符声明依赖，并按顺序将对应引用传给回调。需要持有登记凭据的回调可以将挂载上下文作为第一个参数。插件也可以继续显式实现 `Plugin::Declare` 和 `OnMount`。

安装包示例集中定义整数默认组合。实验复制该配置，通过同一个入口描述符替换一项工厂。工厂为请求该入口的每个作用域返回一个新的 `std::unique_ptr`。`Mount` 在构造提供者前校验需求，再将选中的整数注入回调。显式声明需求的调用者可以通过 `Build` 使用相同的所有权模型。[消费程序源码](../examples/install-consumer/PluginConsumer.cpp)。

工厂可以通过参数接收其他提供者。工厂回调后面的入口描述符按参数顺序声明这些依赖。构建器从请求的入口出发，检查可达依赖图中的缺失绑定、引用类型不匹配和循环，然后先构造依赖，再构造依赖方。多条路径使用的同一入口在每个作用域内共享一个实例。`PluginContext::GetSelections()` 按构造顺序列出入口、实际实现及实验替换标记。[依赖图测试](../tests/install-consumer/ProviderGraph.cpp)。

调用者在登记生效期间持有返回的作用域。作用域先撤销挂载期间的登记，再释放工厂创建的提供者，失败时采用相同的清理顺序。`Borrow` 绑定已有提供者，由调用者管理该对象的生命周期。[工厂与注入测试](../tests/install-consumer/ProviderFactories.cpp)。

## 已确定的方向

| 方向 | 职责与边界 |
| --- | --- |
| 开放插件 | 用户可以定义协议、数据及完整执行流程，官方与用户插件采用相同扩展机制。统一生命周期支持资源管理。版本、依赖及组合由用户管理。 |
| 场景与资产 | 原生中间解析层承接程序化构建及格式适配器，用户可以扩展新格式。 |
| World 生命周期 | 配置、场景编译构建、运行。结构与模型参数在编译后固定，交互使用配置明确支持的输入。 |
| 多 World | 共享兼容只读模型数据，各实例独立保存状态；逐 World 参数及域随机化在编译构建前确定。 |
| 默认研究组合 | CPU 增量势能刚体、约化坐标机构树与自由位姿、理想硬闭环、柔顺法向接触、半光滑 Newton 非光滑静摩擦。 |
| 时间与恢复 | 默认同步批量交互，时间推进支持插件扩展；官方组合提供部分重置和快照恢复路径。 |
| 错误处理 | 官方提供诊断与错误处理示范插件，用户设计错误分类、失败传播、状态有效性和恢复策略。 |
| 使用入口 | C++ 独立使用，Python 支持本地构建、运行和查看，命令行服务可复现实验。 |
| 可视化与后端 | 渲染交由外部渲染器，CPU 优先形成研究路径，Warp 作为可选后端逐步接入。 |

这些方向分别记录在 [ADR 索引](decisions/README.zh-CN.md)。默认研究组合代表一种官方配置，用户可以使用其他模型、求解器及执行流程。实验评价规则适用于官方研究，用户自行决定应用验收。

## 后续接口设计

场景编译器与插件宿主将按用户的选择建立并校验绑定，再挂载插件。句柄表示、数据布局、数学协议、Python 绑定及调度机制随 M1 和后续模块研究确定。传感器保留插件化方向，具体能力待调研。SDF 技术路线及具体实现待专项研究。

[八周实施计划](plans/0002-cpu-research-release.zh-CN.md)按照运行骨架、自由刚体、接触摩擦、多体关节及使用路径推进。多 World 与扩展示例贯穿实施，实际能力按里程碑记录。
