## 当前实现

仓库已提供 C++20 静态库目标 `hibiki::physics`、构建信息接口、安装消费示例及开发环境验证。Windows 工具链、编辑器、调试和环境复现已完成验证，见[验收记录](environment/acceptance.zh-CN.md)。物理算法、World API 和运行插件属于后续实现。

## 已确定的方向

| 方向 | 职责与边界 |
| --- | --- |
| 开放插件 | 用户可以定义协议、数据及完整执行流程，官方与用户插件采用相同扩展机制。统一生命周期支持资源管理。版本、依赖及组合由用户管理。 |
| 场景与资产 | 原生中间解析层承接程序化构建及格式适配器，用户可以扩展新格式。 |
| World 生命周期 | 配置、场景编译构建、运行。结构与模型参数在编译后固定，交互使用配置明确支持的输入。 |
| 多 World | 共享兼容只读模型数据，各实例独立保存状态；逐 World 参数及域随机化在编译构建前确定。 |
| 默认研究组合 | CPU 增量势能刚体、约化坐标机构树与自由位姿、理想硬闭环、柔顺法向接触、半光滑 Newton 非光滑静摩擦。 |
| 时间与恢复 | 默认同步批量交互，时间推进支持插件扩展；官方组合提供部分重置和快照恢复路径。 |
| 错误处理 | 官方提供诊断与错误处理示范插件，用户设计错误分类、失败传播、状态有效性和恢复策略。 |
| 使用入口 | C++ 独立使用，Python 支持本地构建、运行和查看，命令行服务可复现实验。 |
| 可视化与后端 | 渲染交由外部渲染器，CPU 优先形成研究路径，Warp 作为可选后端逐步接入。 |

这些方向分别记录在 [ADR 索引](decisions/README.zh-CN.md)。默认研究组合代表一种官方配置，用户可以使用其他模型、求解器及执行流程。实验评价规则适用于官方研究，用户自行决定应用验收。
