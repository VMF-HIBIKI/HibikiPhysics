# 项目路线图

[English](roadmap.md) | **简体中文**

## 版本目标

首个版本 `v0.1.0` 面向可验证的 C++20 刚体仿真库，提供可运行示例、行为说明与可复现验证。

规划周期为八个开发周，周数从实现启动时计算。范围和验收证据决定里程碑完成状态。

## 优先级

1. C++ 系统工程：所有权、公共接口、构建与打包、诊断和可维护性。
2. 物理实现：明确约定、接触生成、数值积分、约束求解和验证。
3. GPU 探索：范围明确的 Warp 实验及正确性和性能对照。

## 规划范围

| 类别 | 能力 |
| --- | --- |
| 版本必需项 | 刚体状态与积分、选定基础形状、碰撞检测、接触响应、基础摩擦、示例和自动化验证 |
| 随进度加入 | 休眠、简单关节、更多形状和宽相优化 |
| 后续方向 | 软体、流体、可微仿真、通用资产导入和高级编辑工具 |
| 可选实验 | 选定阶段的 Warp 实现，以及 C++ 参考对照 |

形状覆盖和求解器选择在对应实现里程碑进入 Ready 前记录。

## 里程碑

| 里程碑 | 时间 | 交付物 | 验收证据 |
| --- | --- | --- | --- |
| M0：工程基础 | 第 1 周 | 构建、测试、安装及架构基线 | 干净构建、最小安装消费程序、初始自动检查、所有权与数值约定 |
| M1：动力学闭环 | 第 2 周 | 创建刚体、施力、推进与状态访问 | 解析轨迹对照、积分误差研究、生命周期测试、可运行示例 |
| M2：接触闭环 | 第 3–4 周 | 选定基础形状碰撞及接触响应 | 分离/相切/穿透测试、接触约定检查、可复现碰撞场景、回归覆盖 |
| M3：稳定性与测量 | 第 5–6 周 | 选定摩擦和堆叠场景、诊断及基准 | 场景稳定性阈值、数值质量报告、可复现性能基线 |
| M4：发布准备 | 第 7–8 周 | 可安装的 `v0.1.0`、示例、文档和复盘 | 干净环境复现、里程碑验收、发布说明、限制与来源记录 |

Warp 工作在 M3 必需成果完成后具备启动条件，使用独立依赖环境和证据报告。

## 当前实施计划

[Windows 开发环境实施计划](plans/0001-windows-environment.zh-CN.md)细化工程基础工作。首期采用 C++ 静态库，Windows 环境优先，以独立小型用例验收。ENV-001 至 ENV-006 覆盖来源核验、doctor、构建源码、环境准备、编辑器集成和验收，Windows 范围已通过[验收](environment/acceptance.zh-CN.md)。
