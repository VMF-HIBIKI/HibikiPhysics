# 项目路线图

[English](roadmap.md) | **简体中文**

## 版本目标

v0.1.0 面向可运行、可扩展的 C++20 CPU 研究版本，以静态库交付，串起场景编译构建、多 World、默认刚体求解及本地查看。八个有效开发周从实现启动时计算，现有 Windows 环境作为起点。

## 优先级与范围

1. C++ 运行骨架、开放插件、场景编译及独立 World 状态。
2. 自由刚体、增量势能、接触及零滑动静摩擦。
3. 树形多体、基础关节、简单闭环及接触耦合。
4. Python 本地操作、外部查看器及实验复现路径。

广泛形状支持保持长期方向，首先完成球、平面、盒的必要组合，再按进展扩展凸体和其他形状。Warp 仿真后端、CCD、可微分、传感器具体实现、SDF 技术路线及完整关节／机器人格式覆盖属于后续研究。
