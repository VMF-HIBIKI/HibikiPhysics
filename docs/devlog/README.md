# Development logs

**English** | [简体中文](README.zh-CN.md)

Development logs explain technical investigations and their results. English entries use `YYYY-MM-DD-short-title.md`; Chinese entries use `YYYY-MM-DD-short-title.zh-CN.md`. Both editions stay synchronized and provide reciprocal language links.

Each entry covers:

1. The problem and observed behavior.
2. The initial hypothesis and constraints.
3. Experiments and implementation choices.
4. Results, including unsuccessful attempts and their causes.
5. Reproduction commands, environment and relevant commit.
6. Links to decisions and changes.
7. The next planned step.

A weekly cadence provides a consistent project narrative. Each entry centers on concrete evidence and engineering decisions.
